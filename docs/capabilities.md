# 能力范围

五个 Skill 覆盖同一条增长链，不要求每个产品跑完所有渠道，也不把专项工程包装成默认能力。

| 业务问题 | 主要负责 | 具体内容与边界 |
|---|---|---|
| 市场与客户选择 | 01 | 细分、工作流、付费角色、替代方案、切换成本、可达机会与进入条件 |
| 定位与内容 | 02 | 主张和证明、首页/场景/对比页、搜索长文、开发者采用内容、短帖、视频动作与本地化 |
| 发布与分发 | 03 | 发布准备、具体渠道、社媒社区、创作者、媒体目录、搜索与AI发现、应用商店、开源与集成生态 |
| 商业模式与购买 | 01 → 04 → 05 | 01评估机会与单位经济，04确认范围/报价/采购/收款，05检验价格或套餐假设；不代替法务与财务系统 |
| 客户价值 | 04 | Demo与试点、首次价值、使用障碍、生命周期消息、挽回、续费、增购、收入留存 |
| 测量与实验 | 05 | 数据口径、成熟队列、随机分流、低流量学习、渠道重叠、成本与护栏、复盘和投入决定 |
| 分享与推荐 | 按任务交接 | 识别分享动机与真实采用，运营合作与支持，设计机制验证；完整推荐系统、奖励结算和反作弊工程需专门实现 |
| 开发者与开源 | 02 → 03 → 04 | 可运行README与教程、生态分发、社区参与、真实采用与商业机会；不承诺完整维护者治理体系 |
| 消费App与硬件 | 按实际模型调整 | 按地区、设备、自然使用与交付周期判断；不将B2B销售/PH/日活口径强套所有产品，硬件制造和众筹工程需专项工作 |

渠道选择是决策，不是勾选所有平台。没有渠道受众、可用产品入口或服务容量时，先解决相关依赖；早期低流量也能用真实任务、具体承诺和成本记录学习，不必假装已经具备A/B功效。

具体账号发布、付费投放、CRM、支付和线上实验依赖现有工具与授权。没有连接时仍应交付可用材料和待执行包，不能宣称已经完成外部操作。
