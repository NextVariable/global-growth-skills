# Harness 数据与 Skill 契约

[JSON Schema v1](../schemas/v1/harness.schema.json) 保持原垂直切片输入和记录可读，新增阶段、证据字段和工具回执。SQLite 迁移版本单独管理，一库一项目。

| 对象 | 字段与语义 |
|---|---|
| Project Context | 项目 ID、修订版本、事实字段和值。价格与预算使用最小货币单位、币种和期间。市场与目标受众分开。 |
| Evidence / Source | 本机输入按字段版本化。市场来源另记录 HTTPS 来源、日期、有效期、立场、摘录和置信依据。自动来源另存采集时刻、查询范围与选定原字段。区分可复核观察、推断、假设与未验证。 |
| Decision | 建议、证据依赖、所用与可用引用 ID、冲突和审核状态。无法证明真实性时保留 待复核。 |
| Artifact | 草稿类型、Markdown、内容摘要、字段版本依赖、决策和上游产物 ID。历史产物标记 stale 并保留。 |
| Task / Run | 运行 ID、阶段计划、角色 SHA、尝试编号、输入摘要、状态和宿主回执。 |
| Approval / Tool Receipts | 项目、操作 ID、类型、目标和载荷用于绑定授权。消耗、撤回及结果事件由网关生成，模型结果不能提交此类记录。 |

任务输入包含阶段、固定 Skill、最小上下文、证据及交接。战略返回 `recommendation` 与 `citations`，其他阶段返回指定的 `kind` 与 `markdown`。Codex 返回 `claims` 数组，每项含 `source_id` 与逐字 `quote`。没有相关观察时返回空数组。旧 Fixture 和手工导入仍支持省略该字段。任何额外动作字段使结果失败。

依赖记录项目字段版本、活跃决策 ID、上游产物 ID 和来源内容摘要。改价会传播到使用价格的销售和实验方案。已引用来源发生实质内容变化、失去引用资格或被撤回时，沿明确依赖复核。未选择引用的市场草案按候选来源集合复核。导出记录逐字引用数量及需要人工确认的常见定量声明。语义核验、用户理解和业务结果仍需独立评估。
